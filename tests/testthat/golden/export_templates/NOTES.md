# Goldens — `export_templates` (ERC; renamed from `export_roi_cuts` in CRAN item 3)

Generated by `R/sandbox/export_roi_cuts.R` from the **original**
`R/original/export_roi_cuts.R` (read-only reference), as Phase-2 step 1. They
record the original's behaviour **faithfully, bugs included**. Refactor
divergences (below) are derived in the testthat step.

Input `df_rois` is read from the manual fixture `template_trio/rois.duckdb` (real
data whose source recordings exist under `data/`); the DuckDB read is **input
prep**, not the function under test. The original encodes all metadata in the
filename
(`{soundscape}_{start}-{end}s_{min}-{max}kHz_{wl}wl_{ovlp}ovlp_{label}.wav`) and
cuts via `tuneR::readWave(from, to, units="seconds")` → `writeWave`.

## Audio-equivalence anchor

`cuts_manifest.csv` fingerprints every produced cut (n_samples, sample_rate,
channels, md5). The cuts whose names match the hand-made fixture WAVs in
`template_trio/roi_cuts_legacy/` are **byte-identical** (`matches_fixture = TRUE`
for `…075000…` and `…092000…`), proving the original logic reproduces the cuts
the user made by hand in the app. The 2 **new** cuts (`…080000…`, `…081000…`) and
the stereo cut are stored in this golden dir; the 2 matching ones are referenced
by md5 only (not duplicated — they live in the fixture).

## Faithful behaviours captured

- **ERC-04 / ERC-105:** stereo source → stereo cut (no channel selection).
- **ERC-07:** the function returns only the (invisible) `message()` value; the
  per-cut `results` vector is computed and **discarded** (not visible in the
  golden — only messages are).
- **ERC-02:** filename built from rounded bounds + label → collision-prone; here
  no collision occurs, but the `overwrite=FALSE` skip path is exercised (G3a).

## Refactor divergences (asserted in testthat, NOT in the golden)

- **ERC-101:** stop filename-encoding; write a canonical `template_*` schema +
  DuckDB manifest; short stable names. Audio bytes for a given ROI should still
  match the G1 anchor (the cut content is unchanged; only naming/metadata move).
- **ERC-04/105:** cut the **recorded channel** (`roi_channel`); G2 should become a
  **mono** cut of the right channel, with `template_channel` recorded.
- **ERC-07:** return an (invisible) manifest data.frame (status per ROI).
- **ERC-104:** record `origin_soundscape_sha256` + `template_sha256`; derive
  `template_id`.
- **ERC-09:** drop `no_soi` sentinel rows (none present in this fixture).
