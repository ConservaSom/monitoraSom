## Intentional divergences (refactor will CHANGE these — assert as derived)

The refactor applies the DEBT decisions; the testthat step asserts the *new*
behaviour against these goldens rather than byte-equality:

- **FSP-15 (schema, option A)** — the refactored output emits the **canonical
  24-col** `_schema_detections.R` (adds `detection_id`, `template_id`,
  `score_method`), not the legacy **21-col** frame captured here. Tests assert
  the shared 21 columns' *values* match the golden and the 3 new columns are
  present/typed. `template_id` is `NA` for these fixtures (G4 grid predates
  propagation).
- **FSP-12 (empty)** — `synth_edge`, `synth_alltrimmed` (and `synth_monotone`,
  the latent error) must return the **typed zero-row** canonical schema, not a
  bare `data.frame()` / error. Assert `ncol == 24`, `nrow == 0`, correct types.
- **FSP-05 (greedy NMS)** — `synth_tie` must collapse to **1** detection (highest
  score, lowest index wins); `synth_plateau` must collapse to **1** detection at
  the plateau. The golden's 2-row outputs are the *old* behaviour.
- **FSP-01 (plateau)** — flat tops detected as a single peak (folded into FSP-05).
- **FSP-04 (edge margin)** — edge trimming uses `pad_length` (= `sw %/% 2`), not
  the full window, so `synth_edge`'s dominant peak is **retained** (non-empty)
  after the refactor.
- **FSP-09 (quantile population)** — `peak_quant` is computed over the **valid**
  (non-padding) region. Best shown on the **real** fixture (`sw = 172` ⇒ 171
  border-sentinel zeros per edge): the refactor's `peak_quant` differs from the
  golden's full-vector ECDF for the shared peaks (assert `peak_quant` diverges on
  `real_t075_default`). `synth_padquant`'s single dominant peak legitimately stays
  `1.0` in both (it is the maximum) — its interior zeros are not border padding,
  so it does **not** by itself demonstrate the divergence.
- **FSP-10 (top_n provenance)** — `real_t075_top_n1000` records the requested
  `detection_top_n` (capped at available) and emits a **warning**; rows kept.
- **FSP-11 (top_n ordering)** — `top_n` selects by raw `peak_score`, so
  `real_t075_top_n3` may pick a different subset than the quantile-ordered golden.
- **FSP-02/03/14** — robust edge/NA handling and removal of the dead `na.pad`
  arg; no behavioural divergence on these fixtures beyond the empty-case fixes.
- **FSP-08** — docstring `min_score` range + `@return` columns documented (no
  output change).

Note: `synth_edge`, `synth_alltrimmed`, `synth_monotone` all become the same
typed-empty frame after the refactor, so they jointly verify FSP-12's single
empty-result code path.
