## Intentional divergences (refactor will CHANGE these — assert as derived)

These are **expected** to differ in `R/refactored/`; the testthat step encodes the
*corrected* expectation, not the golden value.

- **RMC-01 — padding asymmetry.** The original fills the borders with
  `rep(min, sw_start - 1)` left and `rep(min, sw_end + 1)` right (columns
  `left_fill = sw_start-1`, `right_fill = sw_end+1` in `summary.csv`). The natural
  geometry is `sw_start` / `sw_end`, so the original score series is shifted **one
  frame left** vs `time_vec`. Total length still sums to `n` (hence
  `head_drop = FALSE`), which hides the bug. The refactor uses `pad_left =
  sw_start`, `pad_right = sw_end` and asserts a known-peak-frame alignment → the
  refactored peak frame may differ by **one frame** from the golden. The
  refactored cor is the **conformance anchor** for fft (RMF-05) and dtw.
- **RMC-02 — `head(score_vec, -1)` band-aid.** Removed in the refactor (replaced
  by `stopifnot(length == n_time)`). No observable effect on these fixtures
  (`head_drop = FALSE`) but asserted gone.
- **RMC-03 — `min`-fill / NA replacement.** The original fills borders and
  residual `NA`s with the **per-pair** `min(score_vec)` (visible as the cor
  `score_min` repeated at the edges). The refactor uses the principled sentinel
  **`0`** (no linear association for Pearson), uniform across versions → the
  border values change (golden edges = per-pair min; refactored edges = 0).
- **RMD-02 — per-pair dtw rescale.** dtw scores are `1 - dist/max(dist)`,
  normalized by **this pair's** maximum, so they are **not comparable across
  soundscapes** (note dtw `score_max` is pinned high regardless of a true match —
  cf. Stage 2 `04_dtw.R`). The refactor replaces this with an **absolute**
  normalization (target: by `template_frames × n_bins`), so the refactored dtw
  series will **not** equal the golden — assert the comparability property
  instead (same template over ≥3 soundscapes on a stable scale).
